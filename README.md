# 2026 NLP Internship

A production-ready NLP system for real estate listings. Includes a REST API exposing all capabilities: search, entity extraction, query parsing, classification, summarization, and Fair Housing Act compliance checking.

Database consists of three SQL tables of genuine California real estate data provided by IDX Exhange in February 2026: * rets_property: Active/pending listings with remarks, pricing, features
* rets_openhouse: Open house schedules and details
* california_sold: Historical sold properties with transaction data
